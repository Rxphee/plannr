# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for a security problem. Report it privately through [GitHub's vulnerability reporting](https://github.com/Rxphee/plannr/security/advisories/new) instead.

Include what you found, how to reproduce it and which version you run. Plannr is maintained in spare time, so a first answer may take a few days.

## Supported Versions

Plannr is still in `0.x`. Fixes go into the newest release, so please update to it before reporting.
